# Ajustes — aparência, Strava e backup

> **Árvore:** [docs](../../README.md) › [features](../README.md) › settings
> **Resumo:** Índice da tela **Ajustes**: tema do app, sincronização opcional com o Strava e backup dos seus dados.
> **Tela:** `#/settings` · **Código:** `src/screens/settings/`

## Para que serve

A tela **Ajustes** tem três cartões, nesta ordem:

1. **Aparência**: escolher o tema **Sistema**, **Claro** ou **Escuro**.
2. **Strava** (**Opcional**): trazer suas corridas direto do Strava, sem baixar GPX um por um. **Exige assinatura paga do Strava.**
3. **Backup e restauração**: baixar um arquivo com todos os seus dados e restaurá-lo depois, aqui ou em outro aparelho.

O idioma não fica aqui: use o seletor **EN / PT** no menu.
